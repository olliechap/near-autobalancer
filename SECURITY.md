# Security

Ballast is a hackathon project. The contracts have **not been audited**. Do not put more NEAR in a vault than you are
willing to lose.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub's
[private vulnerability reporting](https://github.com/olliechap/near-ballast/security/advisories/new) for this
repository, with steps to reproduce. You should get a reply within a few days.
